# 西门子 PLC：起保停电机控制（仿真，不用买硬件）

## 目标

用 TIA Portal + PLCSIM 仿真，做一个电机起保停控制回路。

## 点位

- I0.0：启动按钮（常开）
- I0.1：停止按钮（常闭）
- Q0.0：电机运行输出
- Q0.1：运行指示灯

## 梯形图逻辑

1. 启动按钮 I0.0 接通时，Q0.0 置位并自锁。
2. 停止按钮 I0.1 断开时，Q0.0 复位，自锁解除。
3. Q0.1 跟随 Q0.0，电机运行时指示灯亮。

## 仿真验证

1. 在 PLCSIM 里新建仿真 PLC，把程序下载进去。
2. 置位 I0.0，确认 Q0.0 和 Q0.1 变为 1。
3. 断开 I0.0，确认 Q0.0 保持为 1（自锁生效）。
4. 断开 I0.1，确认 Q0.0 和 Q0.1 回到 0。

## 验收

四步仿真现象全部符合上面描述，说明自锁和互锁逻辑正确。
