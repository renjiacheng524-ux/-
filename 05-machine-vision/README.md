# 机器视觉：第一个小练习——找出图里的红色圆点

## 这是上手的第一步，不需要买硬件

只需要一台电脑和 Python。脚本自己生成一张测试图，再用 OpenCV 找出图里的红色圆点。不用摄像头，也不用另外找图片。

## 运行

```bash
pip install opencv-python numpy
python color_detect.py
```

## 预期结果

- 生成一张 `test_image.png`：白底上有红、绿、蓝三个圆点。
- 生成一张 `result.png`：红色圆点被圈出来，旁边标了中心坐标。
- 终端打印找到的红色圆点数量和每个圆点的中心坐标。

## 验收

- 两张图都生成了，`result.png` 里红圈正好套住红色圆点。
- 终端打印的圆点数量是 1（测试图里只有一个红色圆点）。
- 跑通后，试着把颜色范围改成绿色，再跑一次，看能不能找到绿色圆点。

## 之后可以接着练

把输入换成摄像头画面，做实时颜色跟踪；或者换成形状检测（圆、矩形、直线）。
