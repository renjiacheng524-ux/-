# STM32 / C：点灯 + 按键（在线仿真，不用买板子）

## 目标

用在线仿真（Wokwi，支持 STM32）跑通"按键控制 LED"：按一下按键，LED 状态翻转一次。

## 接线（仿真里按这个连）

- LED 接 PA5（板载 LED 引脚）
- 按键接 PC13，按下时为低电平

## 代码

见 `main.c`：初始化 GPIO，循环里检测按键下降沿，每检测到一次就翻转 PA5。

## 运行步骤

1. 打开 Wokwi，新建 STM32 项目，把 `main.c` 的代码贴进去。
2. 按接线图连好 LED 和按键。
3. 点运行，点一下按键，看 LED 亮灭翻转。

## 验收

- 按一下按键，LED 翻转一次；按住不放不重复翻转（下降沿检测生效）。
- 代码能编译通过，没有警告淹没。
