# ROS2：小乌龟 + 第一个发布/订阅节点

## 目标

理解 ROS2 最核心的模型：一个节点发消息，另一个节点收消息。

## 环境

电脑上装 Ubuntu（虚拟机或 WSL 均可），再装 ROS2（版本按官方文档选长期支持版）。

## 练习一：跑通小乌龟

```bash
ros2 run turtlesim turtlesim_node
ros2 run turtlesim turtle_teleop_key
```

用方向键控制小乌龟移动。跑通了，说明 ROS2 环境就绪。

## 练习二：写一个发布/订阅节点（Python）

1. 新建一个包，写一个发布节点：每秒往 `/chatter` 话题发一次字符串。
2. 再写一个订阅节点：收到 `/chatter` 的消息就打印出来。
3. 两个终端分别跑起来，确认订阅端能持续收到发布端发来的消息。

## 验收

- 小乌龟能用键盘控制移动。
- 自己写的发布/订阅节点能跑通，消息从发布端到达订阅端。
